# Pokemon Bot

A Slack bot made with a passion for Pokémon. It was created for stardance.space and is installed on Slack Hack Club.

## Features

- `/pokebuddy-help` - Show available commands
- `/pokebuddy-pokemonfact [pokemon name or id]` - Get a fun fact about a Pokémon
- `/pokebuddy-berrydeets [berry name]` - Get a fun fact about a Berry
- `/pokebuddy-list-berries` - List berries you can ask about
- `/pokebuddy-ping` - Check the bot's latency
- `/pokebuddy-joke` - Get a random joke

## How to use

Head over to The Hack Club Slack and run `/pokebuddy-help` !

## Notes

- The bot uses [Slack Bolt](https://slack.dev/bolt-js/) and [PokeAPI](https://pokeapi.co/).
- Pokémon and berry data come from public APIs, so command output depends on network access.
